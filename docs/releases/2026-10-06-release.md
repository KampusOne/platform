# October 6 release

Android version 0.3.19, build 49. Worker and web source must match the packaged
APK receipt before updating the public APK release or website download pointer.

## Changes

- Recoverable sessions; conversation media previews, upload retries and keyboard
  layout; concise Kira Standard replies and larger Pro context; private documents
  up to 100 MB with resumable uploads and on-device extraction.
- Integer-kobo customer fee pass-through quotes and receipt reconciliation;
  verified vendor publication, referral reporting, featured brands, community
  join requests and authorized bulk approval.
- Exam schedule replacement, first-paper reminders at 120/60/30/15 minutes in
  Lagos time, and owner email-code confirmation that disables one day's alarms.
- Notification preferences, first permission prompt, substantive push content,
  optional academic programme selection and extended streak styling.
- Protected tutorial viewing, initial private R2 storage allowance and subsequent
  Bunny Stream uploads when its server credentials are configured.
- Admin website settings, waitlist shutdown returning 404, editable articles,
  likes, and versioned Android downloads. Rebuilt landing site uses the shared
  authentication API and provides documentation, privacy and terms pages.
- Stable route trimming and alternatives; 665 Overture building footprints added
  to the two UNIBEN campuses. 59 sourced campus centres for 52 other universities
  are available, including 24 source boundaries. These centres do not imply
  complete walking-path or room coverage. Opolo's name is searchable; its exact
  entrance remains unmapped.

## Evidence

Production applied nine exact-source migrations in one transaction. Synthetic
membership, exam and payment fixtures were rolled back. Original accounts,
media, bookings, agent approval records, community rows and ledger projections
were identical before and after. New private tables have RLS and no public
schema/relation/function grants. Existing isolated rehearsal was reused without
reset and is explicitly not represented as a fresh production snapshot.

Local validation: 734 server tests, 156 repository checks and 10 contract tests;
mobile type checking and web export; portal and landing lint/type/build checks.
Browser, deployment and packaged APK receipts are supplied by release workflows.

## Outstanding external verification

Paystack sign-in remains on its login page following secure credential submission;
the account's "Pass fees to customers" preference is not yet verified. The code
does not fabricate an account attestation. Real paid checkout still needs that
preference check and an authorized merchant transaction.

No actual Sabilytics site configuration or native SDK was supplied. Built-in usage
reporting and the existing GA4 integration remain available. Bunny protection
requires its configured library and token key. Native keyboard, gallery, push and
alarm behavior still require testing the installed APK on a physical phone.
