The original public landing site is retained in its existing repository. The mobile header's extra Home link was removed while the menu retains Home. The desktop hero now leaves space between Get app and the students artwork. Sabilytics mounts once on the landing site and Expo web document, using the supplied site/domain identifiers.

Alarms are grouped into Personal, Class timetable, Exams & tests, and Academic calendar. The source dialog leads to a selectable import review. Category/all clearing keeps source schedules and calendar events; repeated imports do not create duplicate reminders. Personal assessments share the existing four-lead exam awareness behavior and survive replacement of an imported exam timetable. The profile strip opens a responsive calendar-based exam-period countdown with a snapshot share.

External content shares use links.kampusone.app. The router validates supported UUID/static/date destinations, saves pending destinations during sign-in, and sends ordinary browsers to the original landing site. Private-message links resolve only for conversation participants. Android association requires the certificate extracted from the actual APK; iOS association still requires a real Apple Team ID. The app web domain is mobile.kampusone.app; app.kampusone.mobile is the package ID.

Storage adds an opt-in direct R2 transport alongside existing uploads. Authenticated quota-limited reservations bind owner, institution, kind, size, file and multipart ID. Clients upload 5 MiB parts to presigned S3 URLs. The server checks actual R2 sizes/ETags, final byte count and a 512-byte MIME prefix before storing metadata. Playback authorizes metadata then signs GET access. Upload and playback bytes bypass the API when direct storage is enabled; the small validation prefix still crosses the Worker. Provider secrets remain server-only, checked with Yup and redacted failures. Disabling direct storage stops new direct tickets and completion; signed playback falls back to the existing proxy. Credentials and bucket CORS must be configured and a real upload/playback verified before activation.
