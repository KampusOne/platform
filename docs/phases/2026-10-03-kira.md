The teaching prompt asks for prerequisites, clear mechanisms, symbols/units, intermediate steps, worked examples, common mistakes, practice questions and explained answers. No client-supplied identity or entitlement grants access. Existing provider-auth failures/kill-switches/shared capacity controls remain enforced; a configured text model can recover from model/capacity failures. Timeout and stale-request handling were adjusted for longer responses.
- Standard/Pro choices now have selection borders/checkmarks consistent with the actual selected tier. Subscription screen explicitly shows the current plan. Pro benefits include30 weekly imports, longer context and teaching answers.
- Learning resource preview can open Kira with **Summarise preview** or **Explain this topic**. Labels explicitly distinguish the visible extract from a complete document; full files are attached in Kira. This does not bypass purchased-resource permissions.
- Replaced moving filled/shadowed rectangles with native transparent gradient strips fixed at the screen perimeter. Warm brand colours crossfade around the edge over6.4 seconds. There is a narrow core and20 logical-pixel inward alpha falloff; the middle is transparent. Animation never translates a shape through content, cannot intercept touches, respects reduced motion, pauses in the background, and stops when Kira is unfocused. Existing top/bottom safe-area layout continues to protect iOS status/DynamicIsland and gesture regions. Added dependency `expo-linear-gradient` was installed by root at the current Expo-compatible version.
- Pending copy reports actual upload/waiting state and changes its waiting guidance as elapsed time increases. It does not pretend to know an upstream model's internal chain of thought or show a fabricated percentage.
- YouTube selection now requires topic relevance before trusted-channel preference. Search candidates are verified using the official videos API: public, processed, embeddable, not age restricted, and available in Nigeria. Missing/failed verification gives a clearly named topic search link; it never fabricates a watch URL. Client cards open both vetted watch links and deterministic topic searches. Provider-written YouTube links are stripped unless they exactly match the trusted adapter's supplied URL. Short video follow-ups use the student's recent topic. References: official YouTube Data API videos resource and Expo LinearGradient docs were checked.
- Added private weekly import reservations. Standard has5combined timetable/calendar/image/document parses per Lagos calendar week, including a3calendar sublimit; Pro has30. Reviewed save/retry does not consume twice. Manual timetable/calendar records and GPA/grade entry never call this helper. Existing daily timetable cap was removed in favour of the weekly allowance. Status exposes used/remaining/reset and calendar usage. Missing migration fails imports visibly while manual entry stays available.
