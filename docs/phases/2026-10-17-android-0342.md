# Android 0.3.42 / build 72

Requested delivery: a new installable APK containing the tutor/vendor listing actions, current tutor identity and verification, learning-resource layout and bookmarks, pinned access action, and refreshed order summary, timeline and reviews from PR #108. The earlier performance, countdown, notification and community work remains included.

This release advances the Android version code from 71 to 72 and updates the existing ARM64 release workflow to publish uniquely named 0.3.42 assets. The package, primary/fallback API origins, source-SHA checks, existing signing certificate, schema readiness checks and deployment receipts are retained. No database migration is added. Build and publication are authorized by the user's request for a new APK.

The implementation passed 400 app checks, 1,157 backend tests, 10 contracts tests, production builds and phone-browser verification before packaging. Release-specific native/web/download receipt tests also pass. The release job must inspect the packaged APK version, architecture, certificate, digest and source revision, then verify the matching deployed backend before publishing; the website pointer additionally requires matching web deployment receipts.
