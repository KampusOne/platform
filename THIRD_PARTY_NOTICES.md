# Mapping code and data

The map provider catalog and Overpass error handling adapt MIT-licensed code patterns from [God's Eye View](https://github.com/bilawalsidhu/gods-eye-view), copyright its contributors. The upstream MIT license is retained in `docs/licenses/gods-eye-view-MIT.txt`. No upstream intelligence datasets, imagery, CCTV or other media are bundled.

MapLibre GL JS is supplied under its upstream BSD license through npm. OpenStreetMap tiles and imported geographic data retain OpenStreetMap contributor attribution and ODbL terms. Imported candidates keep provider feature IDs and source links; imports require review before publication. Esri World Imagery is requested directly from its public service, with provider attribution displayed. Tile requests are interactive only: no prefetching or offline tile archive.

The Ekehuan orientation point comes from the Wikidata African universities directory (CC0). Academic place names are confirmed by official University of Benin pages; building coordinates and entrances are not inferred from names.
